Hi [NAME],

As part of the Invincibility Blueprint® diagnostic, please complete the Director Submission (Company Audit) and upload the supporting information/documentation.

**Form link:** [DIRECTOR_FORM_LINK]
**Deadline:** [DEADLINE]

### Before you start

- Most organisations don't have everything perfectly documented — that's normal.
- Please submit what you already have in whatever format you already have (spreadsheets, exports, screenshots, packs).
- Incomplete is OK — we'll fill gaps through interviews and follow-ups. More is better, but perfection is not required.
- Please don't rewrite documents for this — raw exports and working drafts are more useful than polished summaries.

### How to submit (5 steps)

1. Open the form using the link above.
2. Work through sections in order and answer in free text where asked.
3. Upload any documents requested (or paste SharePoint links if that's easier).
4. If something doesn't exist yet, select "Not available" and briefly explain how it's handled today.
5. Submit — you can contact me if you need to amend anything after submission.
